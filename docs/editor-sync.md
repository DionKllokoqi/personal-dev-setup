# Editor Settings Sync

## VS Code

- Sign in to Settings Sync.
- Enable sync for settings, extensions, keybindings, and snippets.
- Verify settings are pulled after sign-in.

## JetBrains IDEs

- Sign in with your JetBrains account.
- Enable Settings Sync.
- Verify that keymaps, plugins, and editor settings are synced.

## Visual Studio

- Sign in with your Microsoft account.
- Enable Settings Sync (Tools -> Import and Export Settings).
